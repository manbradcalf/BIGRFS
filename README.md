# BIGRFS

Query builder for Neo4j build with React, FastAPI and Neo4j.

BIGRFS stands for

Buildtime Ingestion and Generation, Runtime Filter, Suggest and Search

The idea is to break the graph down into "Chunks" that can be generated at buildtime and used during runtime for query expansion and more.

Designed with the average internet user in mind.
